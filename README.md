# Portfolio Website

A modern, responsive portfolio website showcasing my work as a Technical Product Owner with hands-on engineering expertise.

## Overview

This portfolio demonstrates the intersection of product leadership and technical execution, featuring:

- **About**: Product leadership philosophy and technical foundation
- **Portfolio**: Featured projects with measurable impact
- **Product Impact**: Key metrics and achievements
- **Core Competencies**: Product and technical skills
- **Testimonials**: Feedback from colleagues and stakeholders
- **Contact**: Form for inquiries and collaboration

## Tech Stack

- **React** - UI framework
- **Tailwind CSS** - Styling and responsive design
- **React Icons** - Icon library
- **Vercel** - Deployment platform

## Features

- Fully responsive design (mobile, tablet, desktop)
- Smooth scroll navigation
- Interactive hover effects and animations
- Contact form integration with Getform
- Social media and resume links
- Gradient-based modern design system

## Getting Started

### Installation

```bash
npm install
```

### Development

```bash
npm start
```

Runs the app in development mode at [http://localhost:3000](http://localhost:3000)

### Build

```bash
npm run build
```

Builds the app for production to the `build` folder.
